# Generated rocket and launcher artwork

Created with the built-in ImageGen tool with transparent backgrounds. Original outputs are copied unmodified to `assets/ui/rockets/`. The shop, hangar and flight ammo bar share these assets; the equipped Hellstorm icon appears on its fire/load button. These are original designs, rather than copied DarkOrbit artwork.

Every generation used the following shared prompt, followed by `Subject: ` and its asset-specific subject below.

```text
Use case: stylized-concept. Asset type: original premium 3D inventory icon for the Dorbit space game, displayed small in a dark ammo selector and large in its shop. Square canvas, genuinely transparent RGBA background. Polished silver titanium and dark gunmetal, crisp broad silhouette, detailed but clean hard-surface game render, restrained emissive trim. Isometric three-quarter product view, long axis pointing diagonally from lower left to upper right, entire item centered, occupies 80% of canvas with clear transparent margin. Bright neutral studio key from upper left, soft fill. Original space-game engineering matching metallic laser-energy cartridge icons. No text, labels, letters, numbers, logos, watermark, frame, floor, cast shadow, explosions or background. No active exhaust: this is an inventory item, not an in-flight projectile.
```
