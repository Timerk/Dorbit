# Extras artwork

Seven original square item illustrations generated with the built-in ImageGen
tool, copied into this project and used by both shop previews and inventory tiles.
The silver/graphite materials, copper trim and navy backdrop match the equipment
catalog. `prompts.json` records every exact final generation prompt.

| Image | Item |
| --- | --- |
| `rep-1.png` | REP-1 Repair Robot |
| `rep-2.png` | REP-2 Repair Robot |
| `repair-auto.png` | NC-RRB Repair Auto CPU |
| `cargo-expander.png` | GEMINEX-XI Cargo Expander |
| `slot-cpu-1.png` | Slot CPU 1 |
| `ammo-cpu.png` | Ammunition CPU |
| `generator-cpu.png` | Generator Boost CPU |

These are inventory illustrations, not flight meshes. No DarkOrbit image assets
are used. Mechanics and tuning live in `GAME_PLAN.md`.
