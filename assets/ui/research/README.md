# Research skill artwork

Eleven original equipment illustrations generated with the built-in ImageGen
tool. Each square PNG is named for its `Research.SKILLS` ID and used in the
research tree and selected-skill detail panel. Defense accents are cyan, Economy
violet and Offense orange-red; titanium, graphite and cobalt match the game's
industrial equipment art. The dark backgrounds are intentional and opaque.

Labels, levels, selection and lock states remain live Godot controls. Images
preserve their aspect ratio and ignore mouse input so the whole node is clickable.

Exact generation prompts: [prompts.md](prompts.md).
