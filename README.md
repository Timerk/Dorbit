# Dorbit

A space game inspired by DarkOrbit, planned for Windows with Godot. Full 3D flight, target-lock combat, alien hunting, and multiplayer for approximately 10 players form the initial scope.

The project is in planning. There is no playable build yet.

- [Game requirements and development plan](GAME_PLAN.md)
- [Development workflow](AGENTS.md)

The first milestone is a small sector where a player can fly around a station, fight an alien, collect a reward, and return to repair.
